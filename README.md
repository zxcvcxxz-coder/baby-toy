# Baby Toy App 👶🎨

赤ちゃんがキーボードを叩いて遊べる、キーボード誤操作防止＆知育視覚エフェクトアプリです。

Pygame と `keyboard` ライブラリを使用して、Windows のシステムキーを含むキーボード入力をフック・ブロックし、赤ちゃんがキーボードを連続で押してもPCが誤作動しないように保護します。キーを押すごとに画面にカラフルな文字やパーティクルエフェクトが表示されます。

---

## ✨ 特徴

- 🔒 **キーボードブロック機能**
  - Windowsキーやファンクションキーなどのシステムキーを含め、キーボード入力を安全にフック・制御（suppress）します。
- 🎨 **インタラクティブな視覚エフェクト**
  - 許可されたキーが押されると、背景色がランダムに変化し、押したキーの文字やパーティクルアニメーションが発生します。
  - `A` キーを押すとアルファベットが画面上部から降り注ぐ「アルファベットレイン」などの特殊演出を搭載。
- 🔑 **安全な終了機能**
  - 赤ちゃんが偶然終了させないよう、秘密の終了コマンド（キーを順番に `q` -> `u` -> `i` -> `t` と入力）または `ESC` キーで安全にアプリを終了できます。

---

## 🛠 動作環境・依存ライブラリ

- **OS**: Windows (管理者権限推奨: `keyboard` ライブラリによるシステムキーフックのため)
- **Python**: 3.8 以上

### 依存パッケージ
- `pygame`
- `keyboard`

## 🚀 セットアップ & 実行方法

### 1. リポジトリのクローン
```bash
git clone git@github.com:zxcvcxxz-coder/baby-toy.git
cd baby-toy
```

### 2. 依存パッケージのインストール
```bash
pip install -r requirements.txt
```

### 3. アプリケーションの起動
管理者権限を持つ端末（コマンドプロンプトや PowerShell）で実行してください。
```bash
python main.py
```

---

## 🎮 使い方

1. アプリを起動すると、5秒間のカウントダウンが表示された後、全画面（またはウィンドウモード）でアプリが立ち上がり、キーフックが有効化されます。
2. キーボードのキーを自由に押して遊んでください。
3. アプリを終了する場合は、キーボードで **`q` `u` `i` `t`** を順番に入力するか、**`ESC`** キーを押してください。
